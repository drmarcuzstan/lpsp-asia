# LPSP Asia website

Static website for LPSP Asia Pte. Ltd. (UEN 202113514H) — English, Simplified Chinese and German.

- `index.html` — the full site (language switch built in; `#en`, `#zh`, `#de` open a language directly)
- `img/` — photography (Unsplash licence)
- `favicon.svg`, `apple-touch-icon.png` — LPSP monogram

Hosted with GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
